Variables

변수 — 도형의 위치와 크기를 담는 그릇.

화면 위 원의 위치(x, y)와 크기, 색상은 모두 변수에 담겨 있습니다. 슬라이더를 움직이면 변수 값이 바뀌고, 그 값을 참조하는 원도 함께 바뀝니다.

let x = 150;
let y = 150;
let size = 80;

fill(color);
ellipse(x, y, size, size);

Conditionals

조건문 — 위치에 따라 다르게 반응하기.

마우스가 캔버스의 왼쪽에 있는지 오른쪽에 있는지에 따라 원의 색이 달라집니다. 같은 코드라도 조건에 따라 전혀 다른 결과를 만들 수 있습니다.

if (mouseX < width / 2) {

PAGE 03 · LOOP

Loops

반복문 — 같은 모양을 지치지 않고 반복.

원 하나를 그리는 코드를 count번 반복해서, 방사형으로 퍼지는 점 패턴을 만듭니다. 개수를 늘릴수록 패턴은 더 촘촘하고 복잡해집니다.

for (let i = 0; i < count; i++) {
    let angle = (TWO_PI / count) * i;
    let x = cx + cos(angle) * 100;
    let y = cy + sin(angle) * 100;
    ellipse(x, y, 14, 14);
}

Q. count를 10에서 40으로 늘리면 어떤 변화가 생길까요?

PAGE 04 · FUNCTION

Functions

함수 — 한 번 만들고, 계속 찍어내기.

'도장 찍기' 버튼을 누를 때마다 같은 stamp() 함수가 다른 위치·크기·색으로 호출됩니다. 함수를 만들어두면 같은 로직을 계속 재사용할 수 있습니다.

function stamp(x, y, size, col) {
    fill(col);
    ellipse(x, y, size, size);
}

stamp(80, 80, 40, red);    // 재사용 1
stamp(200, 150, 60, blue); // 재사용 2

STAGE 01 · ARRAY

Arrays

배열 — 여러 개의 값을 한 번에 다루기.

화면 위 여러 개의 원이 각자 다른 속도로 떠다닙니다. 각 원의 상태는 배열 하나에 담겨 있고, 반복문으로 배열 전체를 순회하며 한 번에 업데이트합니다.

let dots = [];

for (let i = 0; i < count; i++) {
    dots.push({ x: random(width), y: random(height), vy: random(1, 3) });
}

dots.forEach(d => {
    d.y = (d.y + d.vy) % height;
    ellipse(d.x, d.y, 8, 8);
});

Q. dots 배열의 길이를 30에서 100으로 늘리면 어떻게 될까요?

STAGE 02 · NOISE

Perlin Noise

노이즈 — 무작위지만 자연스러운 움직임.

random()은 값이 매 순간 뚝뚝 끊기지만, noise()는 부드럽게 이어지는 값을 만들어 유기적인 움직임을 표현합니다. 미디어 아트에서 자연스러운 흔들림을 만들 때 자주 쓰입니다.

let t = 0;

function draw() {
    let x = noise(t) * width;
    let y = noise(t + 100) * height;
    ellipse(x, y, 24, 24);
    t += speed;
}

Q. noise()와 random()의 가장 큰 차이는 무엇일까요?

STAGE 03 · OBJECT

Objects & Classes

객체 — 데이터와 동작을 하나로 묶기.

Particle 클래스 하나를 만들어두면, 클릭할 때마다 위치·속도를 각자 가진 독립적인 입자를 계속 만들어낼 수 있습니다. 캔버스를 클릭해 입자를 흩뿌려보세요.

class Particle {
    constructor(x, y) {
        this.x = x;
        this.y = y;
        this.vx = random(-2, 2);
        this.vy = random(-2, 2);
    }
    update() {
        this.x += this.vx;
        this.y += this.vy;
    }
}

STAGE 04 · EVENT

Events

이벤트 — 사용자의 입력에 반응하기.

방향키(또는 버튼)를 누르면 사각형이 이동합니다. keyPressed() 같은 이벤트 함수는 사용자의 행동에 실시간으로 반응하는 인터랙티브 작업의 기본입니다.

function keyPressed() {
    if (keyCode === LEFT_ARROW)  x -= 10;
    if (keyCode === RIGHT_ARROW) x += 10;
    if (keyCode === UP_ARROW)    y -= 10;
    if (keyCode === DOWN_ARROW)  y += 10;
}

Color Modes

색상 모드 — 무지개처럼 색을 순환시키기.

colorMode(HSB)를 사용하면 색상(Hue)만 계속 바꿔가며 자연스럽게 순환하는 무지개색을 만들 수 있습니다. RGB보다 색을 직관적으로 다룰 수 있어 제너레이티브 아트에서 즐겨 사용됩니다.

colorMode(HSB, 360, 100, 100);
let hue = 0;

function draw() {
    fill(hue, 80, 90);
    ellipse(x, y, 40, 40);
    hue = (hue + speed) % 360;
}

let angle = noise(x * scale, y * scale) * TWO_PI;
let target = atan2(mouseY - y, mouseX - x);
angle += atan2(sin(target - angle),
               cos(target - angle)) * influence;
line(x, y, x + cos(angle) * 16,

Recursive Trees

재귀 — 작은 규칙으로 자라는 구조.

가지가 자기 자신을 더 짧게 호출하며 나무를 만듭니다. 종료 조건이 있어야 재귀가 멈춥니다. 마우스를 좌우로 움직이면 가지가 펼쳐지고, 깊이를 높이면 더 촘촘해집니다.

function branch(length, depth) {
  if (depth === 0) return;
  line(0, 0, 0, -length);
  translate(0, -length);
  for (let side of [-1, 1]) {
    push(); rotate(angle * side);
    branch(length * 0.68, depth - 1);
    pop();
  }
}
